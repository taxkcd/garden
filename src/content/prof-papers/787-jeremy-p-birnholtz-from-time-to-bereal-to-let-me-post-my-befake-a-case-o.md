## Paper overview

This paper studies how the social media app BeReal tries to encourage users to share authentic moments by prompting spontaneous photo posts. Through interviews with 25 users, the authors find that users experience authenticity in two ways: posting spontaneously and presenting a true self. However, users often balance authenticity with other values like privacy, autonomy, and the desire to save memories, leading them to sometimes delay or curate posts, which conflicts with BeReal's design. The paper highlights the challenges of designing for authenticity on social media and the tensions users face in practice.

### Why it matters

**Research problem:** How social media platforms can operationalize and encourage authentic online behavior, given the complex, contextual, and value-laden nature of authenticity.

**Why it matters:** Authentic online behavior is linked to improved psychological well-being, but social media platforms often promote curated, inauthentic content which can harm users' mental health. Understanding how to design platforms that support authentic self-presentation can help address social media's negative effects and improve user well-being.

**Key contributions:**

- Identification of two facets of authenticity in practice: impromptu posting and representative self-presentation.
- Demonstration of tensions between BeReal’s design-driven operationalization of authenticity and users’ lived experiences and values.
- Highlighting how authenticity conflicts with other values like privacy, autonomy, and reminiscence in social media use.
- Providing design implications for balancing authenticity with contextual and value-based complexities in social media platforms.

### Beginner — Simulate BeReal's Spontaneous Posting Prompt
*Effort: a weekend, ~8 hours*

You build a simple web app that simulates BeReal's daily spontaneous posting prompt with a two-minute window. The app randomly selects a time each day and prompts the user to upload two photos (front and back camera) within the time window, disallowing edits. You implement basic UI feedback for on-time, late, or missed posts.

**Why it shows you understood the paper:** This project shows you understand the paper's key operationalization of authenticity as spontaneous, unfiltered posting within a strict time window, and the constraints BeReal places on users.

**Grounded in:** BeReal operationalizes authenticity as spontaneous, unfiltered posting within a two-minute prompt.

**Tech stack:** TypeScript, React, CSS

**Data:** No external data needed; you simulate the prompt timing and user interaction.

**Build it:**

1. Create a React app with a timer that randomly selects a daily prompt time.
2. Implement a UI that notifies the user when the prompt is active with a two-minute countdown.
3. Allow the user to upload two photos (front and back camera) only during the prompt window.
4. Disable photo editing or re-uploading after the window closes.
5. Show feedback messages for on-time, late, or missed posts.

**Ships as:** A GitHub repo with a React app demonstrating the spontaneous posting prompt and timing constraints, with a README explaining the connection to BeReal's design.

**Stretch goal:** Add a feature to log user behavior over multiple days and visualize on-time vs late posting rates.
