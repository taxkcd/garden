## Paper overview

This paper argues that AI systems acting as agents in social environments should be designed using social theory as a foundational framework. It introduces the Multi-Agent Social Systems (MASS) model, which formalizes how heterogeneous agents (human and AI) interact over networks, influencing each other and producing emergent social outcomes. The authors identify four key structural properties—strategic heterogeneity, network-constrained dependence, co-evolution, and distributional instability—that distinguish these systems from traditional single-agent AI models. They demonstrate these properties empirically using MoltBook, a social media platform of AI agents, and propose a research agenda for modeling, evaluating, and governing such multi-agent systems.

### Why it matters

**Research problem:** Current agentic AI systems are mostly designed and evaluated as isolated or homogeneous units focused on individual task performance, ignoring the complex social interactions and emergent dynamics that arise when multiple heterogeneous agents interact in networked social environments.

**Why it matters:** As AI agents increasingly operate within social environments alongside humans and other agents (e.g., social media, multi-agent LLM pipelines), understanding and governing their collective behavior is critical to prevent harmful emergent phenomena like coordinated manipulation, echo chambers, and distributional drift that cannot be addressed by focusing on individual agents alone.

**Key contributions:**

- Formalization of MASS framework integrating social theory as structural priors for agentic AI systems.
- Identification and formal proof of four structural priors: strategic heterogeneity, network-constrained dependence, co-evolution, and distributional instability.
- Empirical validation of these priors using large-scale data from MoltBook, an AI-agent social media platform.
- Articulation of a research agenda including modeling, evaluation, and governance principles for multi-agent AI systems.
- Clarification of distinctions between MASS and related fields such as multi-agent reinforcement learning, social simulation, and alignment research.

**Why it shows you understood the paper:** This project concretely demonstrates the paper's concept of strategic heterogeneity by reproducing the empirical observation that agents with different roles and network positions exhibit distinct behaviors, showing you grasp the core structural prior.

**Grounded in:** Key result: Strategic heterogeneity - Agents with different roles and network positions exhibit distinct engagement trajectories and influence patterns.

**Tech stack:** Python 3.11, NetworkX, Matplotlib, Jupyter Notebook

**Data:** Synthetic data generated by simulating a small network of 20-30 agents with assigned roles and influence parameters.

**Build it:**

1. Set up a Python environment with NetworkX and Matplotlib.
2. Create a small synthetic network graph with heterogeneous agent nodes assigned distinct roles.
3. Implement simple agent state update rules reflecting influence and engagement over discrete time steps.
4. Run the simulation and record agent engagement metrics over time.
5. Visualize engagement trajectories grouped by agent roles and network positions.
6. Write a README explaining how the simulation reproduces strategic heterogeneity as described in the paper.

**Ships as:** A Jupyter notebook with simulation code, visualizations of agent engagement trajectories by role, and a README linking the results to the paper's strategic heterogeneity prior.

**Stretch goal:** Add simple influence dynamics where agents update states based on neighbors' states to begin exploring network-constrained dependence.
