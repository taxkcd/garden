## Paper overview

This study evaluates how the WebTA code critiquing tool affects programming self-confidence among first-year engineering students, focusing on gender differences. It finds that WebTA significantly improves programming self-efficacy for both male and female students, with particularly notable gains for female students, helping to close the confidence gap in programming skills.

### Why it matters

**Research problem:** Female engineering students often have lower programming self-efficacy than males, which contributes to gender disparities in technology fields. There is a lack of research on how educational interventions like immediate feedback tools impact programming self-efficacy differently by gender.

**Why it matters:** Programming self-efficacy influences student engagement, persistence, and success in engineering. Addressing gender disparities in self-efficacy is critical to promoting equity and retaining more women in computing and engineering disciplines.

**Key contributions:**

- Demonstrated significant improvements in programming self-efficacy for first-year engineering students using WebTA.
- Provided evidence that female students showed larger gains in programming self-efficacy, helping to close the gender confidence gap.
- Validated the use of immediate feedback tools like WebTA in a MATLAB programming context, extending prior Java-based research.
- Highlighted the stability of broader engineering self-efficacy despite gains in programming-specific self-efficacy.
- Offered a detailed analysis of gendered impacts of code critiquers on self-efficacy, addressing a critical research gap.
