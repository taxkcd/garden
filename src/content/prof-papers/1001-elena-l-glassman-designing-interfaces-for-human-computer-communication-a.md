## Paper overview

This paper presents a detailed framework describing the conversational loop between humans and AI systems during communication. It breaks down the steps from forming an intent, expressing it, AI inference, feedback, and human evaluation, highlighting where communication can fail and how interface design can improve this interaction.

### Why it matters

**Research problem:** How to effectively design interfaces and algorithms that support clear and accurate communication between humans and AI systems, accounting for the complex cognitive and computational steps involved in human-AI conversations.

**Why it matters:** As AI systems become more integrated into daily tasks, misunderstandings between human intent and AI interpretation can lead to errors, inefficiencies, and user frustration. Improving communication interfaces can enhance usability, trust, and effectiveness of AI-assisted systems.

**Key contributions:**

- A detailed framework modeling the human-AI communication loop with cognitive and computational steps.
- Identification of potential failure points in communication and suggestions for interface design improvements.
- Integration of concepts from psychology and human-computer interaction to inform AI system design.
- Discussion of cognitive limitations and heuristics affecting human interaction with AI.
- Presentation of feedback mechanisms to improve shared understanding between human and AI.

**Why it shows you understood the paper:** This project demonstrates your grasp of the paper's core framework by faithfully reproducing its conceptual model in an accessible, interactive format, making the communication loop and its failure points explicit.

**Grounded in:** The paper presents a detailed framework modeling the human-AI communication loop with cognitive and computational steps.

**Tech stack:** JavaScript, React, CSS

**Data:** No external data needed; the project uses the paper's framework descriptions as content.

**Build it:**

1. Create a React app with a main visualization component representing the communication loop as a cycle.
2. Implement clickable nodes for each step (intent formation, expression, AI inference, feedback, evaluation).
3. Add explanatory tooltips or side panels that show descriptions and failure points for each step.
4. Style the visualization for clarity and accessibility.
5. Test the interaction flow to ensure users can understand the loop and failure points.

**Ships as:** A GitHub repository with a React app and README explaining the communication loop visualization and how it maps to the paper's framework.

**Stretch goal:** Add a simple simulation mode where users can input an intent and see how it might fail or succeed through the loop stages.

**Why it shows you understood the paper:** This project operationalizes the paper's emphasis on feedback mechanisms as critical for shared understanding, showing you can implement interface elements that reduce communication failures by making AI inference transparent.

**Grounded in:** Feedback mechanisms are critical for shared understanding.

**Tech stack:** TypeScript, React, Node.js, Express.js

**Data:** No external dataset; simulated user intents and AI inference outputs are generated within the app.

**Build it:**

1. Set up a full-stack TypeScript React + Node.js project.
2. Implement a text input interface for users to express intents.
3. Create a mock AI inference module that returns inferred intents, confidence scores, and action previews.
4. Design UI components to display AI feedback clearly, including inferred intent and preview of effects.
5. Allow users to confirm or correct the AI's inference, simulating the evaluation step.
6. Log interaction data to analyze communication success and failure points.

**Ships as:** A GitHub repo with a working prototype demonstrating feedback loops in human-AI communication and a README linking features to the paper's framework.

**Stretch goal:** Integrate a simple heuristic model of cognitive load to limit feedback verbosity dynamically.
