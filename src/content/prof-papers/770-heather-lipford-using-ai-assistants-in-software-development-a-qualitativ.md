## Paper overview

This study explores how software professionals use AI assistants like ChatGPT and GitHub Copilot in software development, focusing on security practices and concerns. Through interviews with 27 professionals and analysis of Reddit discussions, the research finds that despite mistrust in AI-generated code security, AI assistants are widely used for security-critical tasks such as code generation, threat modeling, and vulnerability detection. Users critically review AI suggestions, expecting future improvements to increase AI use in security tasks. The paper offers recommendations for developers, AI creators, and researchers to improve security and ethical use of AI assistants.

### Why it matters

**Research problem:** While AI assistants are increasingly used in software development, their impact on software security and how professionals balance AI usage with security concerns remain unclear.

**Why it matters:** AI-generated code can contain security vulnerabilities, and improper reliance on AI assistants may introduce risks. Understanding how professionals use and scrutinize AI suggestions is critical to ensuring secure software development in an era of widespread AI adoption.

**Key contributions:**

- First qualitative insights on how software professionals use AI assistants in the context of software security.
- Identification that professionals widely use AI assistants for security-critical tasks despite mistrust, replacing traditional advice sources like Google and Stack Overflow.
- Recommendations for software professionals to critically check AI suggestions, for AI creators to improve security and ethical safeguards, and for researchers to study general-purpose AI in software development.
- Provision of artifacts for transparency including interview guides and Reddit analysis.
