## Paper overview

This paper discusses knowledge-guided machine learning (KGML), which integrates scientific knowledge with machine learning to create AI models that are more accurate, interpretable, and consistent with scientific principles. KGML aims to overcome limitations of purely data-driven AI and traditional mechanistic models by combining their strengths, enabling better scientific discovery and modeling.

### Why it matters

**Research problem:** Purely data-driven AI models often lack interpretability, generalizability, and consistency with scientific principles, while traditional mechanistic models can be limited by incomplete knowledge and computational costs. There is a need for AI methods that integrate scientific knowledge to improve robustness, trustworthiness, and scientific validity.

**Why it matters:** Scientific applications require AI models that respect established physical, biological, or chemical laws to be credible aides in discovery. Overcoming the limitations of black-box AI and imperfect mechanistic models can accelerate scientific modeling, discovery, and understanding across diverse domains.

**Key contributions:**

- A comprehensive taxonomy organizing KGML research across multiple dimensions.
- Identification of opportunities such as improved out-of-distribution generalization and scientific knowledge advancement.
- Discussion of challenges including knowledge representation diversity, need for benchmarks, interdisciplinary training, and ethical considerations.
- Presentation of KGML as a paradigm shift combining explanatory power of scientific knowledge with adaptability of ML.

### Beginner — Physics-Informed Regression with Synthetic PDE Constraints
*Effort: a weekend, ~8 hours*

You build a simple regression model that predicts a physical quantity from synthetic data, incorporating a physics-based constraint expressed as a partial differential equation (PDE) residual as a regularizer. This small project demonstrates how embedding scientific knowledge into the loss function improves model consistency.

**Why it shows you understood the paper:** This project shows you understand the concept of knowledge-guided learning by explicitly integrating a scientific constraint (PDE) into a machine learning model, illustrating the paper's taxonomy dimension of knowledge format and incorporation method.

**Grounded in:** Demonstrates the paper's key contribution that incorporating knowledge directly in the learning algorithm improves scientific consistency and generalizability.

**Tech stack:** Python 3.11, PyTorch, Jupyter Notebook

**Data:** Synthetic dataset simulating a physical system governed by a known PDE (e.g., heat equation) generated programmatically.

**Build it:**

1. Generate synthetic data from a known PDE with added noise to simulate observations.
2. Implement a baseline regression model (e.g., feedforward neural network) to predict the target variable.
3. Define a PDE residual loss term representing the physics constraint.
4. Train the model with combined data loss and PDE residual loss (knowledge-guided).
5. Compare performance and consistency of the knowledge-guided model against the baseline.
6. Document results and explain how the PDE constraint improves interpretability and generalizability.

**Ships as:** A GitHub repo with code and a README showing the synthetic data generation, model training with PDE constraints, comparison plots, and explanation of knowledge integration benefits.

**Stretch goal:** Add visualization of out-of-distribution generalization by testing on data from a shifted domain.
