## Paper overview

This study analyzes a large dataset of code generated by large language models (LLMs) across multiple programming languages to understand the types and frequencies of errors in AI-generated code. It finds that despite improvements, LLMs still frequently make basic mistakes such as missing imports and boundary errors, which can cause reliability and security issues. The study also examines how error patterns vary by language, model, and problem difficulty, and evaluates the effectiveness of feedback and prompting strategies in reducing errors.

### Why it matters

**Research problem:** LLMs are increasingly used for code generation, but their generated code often contains errors. Prior studies on these errors are limited in scope, focusing on few languages, models, or small datasets, lacking a comprehensive understanding of error types and their causes across languages and models.

**Why it matters:** Understanding error modes in LLM-generated code is critical to set realistic expectations, design mitigation strategies, and ensure the reliability and security of AI-assisted software development, especially as AI-generated code becomes more prevalent in production environments.

**Key contributions:**

- Largest analysis of errors in LLM-generated code to date, covering 86,726 errors across seven models and four compiled languages.
- Detailed characterization of error types and their variation across models, languages, and problem difficulty.
- First evaluation of iterative feedback impact on error correction across multiple models and languages.
- Refined and adapted error taxonomies for cross-language classification of compilation and runtime errors.
- Public release of the experimental pipeline and labeled dataset for reproducibility.
