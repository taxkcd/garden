## Paper overview

This paper explores how procedural content generation (PCG) in video games, a form of computational creativity, intersects with feminist theory and politics. It examines how algorithms that create game content can embed social biases and political messages, and argues for designing PCG systems with awareness of cultural context and social justice. The authors analyze the gendered history of artificial intelligence and discuss how computational creativity challenges traditional notions of authorship and labor in game design.

### Why it matters

**Research problem:** Procedural content generation systems in games often embed unexamined social biases and political messages, complicating authorship and responsibility. There is a lack of feminist-informed design approaches that consider difference, power, and cultural context in computational creativity.

**Why it matters:** As games increasingly rely on PCG, the embedded biases in algorithms can perpetuate harmful stereotypes and social injustices. The game industry faces challenges related to labor practices and diversity, making it crucial to critically assess the politics of computational creativity to foster socially responsible game design.

**Key contributions:**

- A feminist theoretical framework for assessing the politics of procedural content generation in games.
- Analysis of the gendered history of AI and its influence on perceptions of computational creativity.
- Case studies of generative systems (e.g., ANGELINA, A Rogue Dream) illustrating embedded biases and political implications.
- Discussion of authorship, labor, and ethical considerations in computational creativity research.
- Recommendations for designing PCG systems that are culturally aware and socially responsible.

### Beginner — Bias Analysis of Procedural Text Generation Using Google Autocomplete Data
*Effort: a weekend, ~8 hours*

You build a small web app that queries Google Autocomplete API (or simulates it with a static dataset) to collect autocomplete suggestions for gendered or culturally sensitive seed phrases. Then you analyze and visualize the frequency of biased or stereotypical completions (e.g., sexist or racist terms) using simple charts.

**Why it shows you understood the paper:** This project concretely reproduces the paper's example of how reliance on popular data sources like Google Autocomplete can embed harmful biases in PCG outputs, demonstrating awareness of algorithmic bias and cultural context.

**Grounded in:** Key result: 'Examples like A Rogue Dream demonstrate how reliance on popular data sources (e.g., Google autocomplete) can result in offensive or inappropriate game content.'

**Tech stack:** JavaScript, React, D3.js or Chart.js, Node.js (optional for API proxy)

**Data:** Google Autocomplete suggestions for selected seed phrases; if API access is unavailable, use a small curated static dataset simulating autocomplete results with biased content.

**Build it:**

1. Select a set of seed phrases related to gender and culture (e.g., 'women are', 'men are', 'immigrants are').
2. Fetch autocomplete suggestions for each phrase using Google Autocomplete API or load a static dataset.
3. Parse and categorize suggestions for presence of biased or stereotypical language.
4. Visualize the distribution of biased vs neutral completions using bar charts or word clouds.
5. Write a README explaining the connection to the paper's analysis of A Rogue Dream and algorithmic bias.

**Ships as:** A GitHub repository with a React app that visualizes biased autocomplete suggestions, accompanied by a README linking the demo to the paper's critique of PCG bias.

**Stretch goal:** Add user input to allow testing arbitrary seed phrases and dynamically update bias visualizations.

### Intermediate — Procedural Narrative Generator with Bias Detection and Ethical Filtering
*Effort: 2 weekends, ~20 hours*

You implement a simple procedural narrative generator that produces short game story snippets by combining templates and word lists. You integrate a bias detection module (e.g., keyword-based or using a pretrained toxicity classifier) to flag or filter out outputs containing sexist, racist, or stereotypical language. You compare the filtered generator against a baseline without filtering and report metrics on bias reduction.

**Why it shows you understood the paper:** This project operationalizes the paper's core concern about embedded biases in PCG systems and the ethical responsibility of designers to mitigate harmful content, demonstrating an applied feminist-informed design approach.

**Grounded in:** Key contribution: 'Recommendations for designing PCG systems that are culturally aware and socially responsible.' **Tech stack:** Python 3.11, FastAPI, React (optional frontend), Pretrained toxicity classifier (e.g., Detoxify or Perspective API)

**Build it:**

3. Implement a procedural generator that randomly fills templates to produce narratives.
4. Integrate a bias detection module using a pretrained toxicity classifier or keyword filter.
5. Filter or flag generated narratives containing biased or harmful content.
6. Compare the number and proportion of biased outputs before and after filtering; document results.
7. Write a README linking the project to the paper's feminist design recommendations.

**Ships as:** A GitHub repo with code for the narrative generator, bias detection module, and a report comparing bias metrics with and without filtering, plus documentation relating to the paper.

**Stretch goal:** Add a user interface to allow users to generate narratives and see bias warnings in real time.
