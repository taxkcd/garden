# 309 · Little Procedural People: Playing politics with generators

## At a glance

- **Year:** 2017

## Paper overview

This paper explores the social and political implications of procedural content generators that create or involve people, such as characters in games or bots on social media. It identifies four key areas where generative systems intersect with social responsibility: generating social characters, using real-world data, employing cultural signifiers, and modeling human possibilities. The author argues for ethical awareness and responsibility in designing these systems.

### Why it matters

**Research problem:** How do procedural content generators that create or involve representations of people carry political and social implications, and what responsibilities do creators have in designing these systems?

**Why it matters:** Generators that create or interact with people can unintentionally reinforce stereotypes, exclude identities, or cause ethical issues when using real data or cultural signifiers. As generative systems become more common, understanding and addressing these concerns is crucial to avoid harm and promote inclusivity.

**Key contributions:**

- Identification of four key areas where generativity intersects with politics and social responsibility.
- Discussion of ethical challenges in generating social characters and bots.
- Analysis of issues arising from using real-world data and locations in generative systems.
- Examination of the use and risks of cultural and social signifiers in generators.
- Highlighting how modeling human possibilities encodes beliefs and exclusions.

## Build it — 3 projects to showcase this paper

_A beginner, an intermediate and an advanced project, each tied to a specific claim in this paper. Build one and it becomes concrete evidence that the paper was understood, not just read._

These three projects form a ladder to demonstrate understanding of the social and ethical implications of procedural content generators involving people, as discussed in the paper. The beginner project focuses on reproducing a simple ethical safeguard mechanism for social bots, the intermediate project implements a generator that uses cultural signifiers with basic filtering to avoid stereotypes, and the advanced project extends this by designing an inclusive character generator that models diverse human identities while addressing ethical challenges highlighted by the paper.

### Beginner — Social Bot Ethical Behavior Filter
*Effort: a weekend, ~8 hours*

You build a simple Twitter bot simulator that generates social character messages and implements basic ethical filters to block offensive or unethical content, inspired by the paper's discussion of social bots needing ethical behavior similar to humans. The bot will generate messages based on predefined templates and filter out content flagged as unethical or stereotypical.

**Why it shows you understood the paper:** This project shows you understand the paper's key result that social bots must follow ethical rules similar to humans and that safeguards are necessary to prevent harmful content generation.

**Grounded in:** Social bots on platforms like Twitter must consider ethical behavior similar to humans, including rules of engagement and content generation.

**Tech stack:** Node.js, JavaScript, Express.js, Jest (for testing)

**Data:** You simulate bot-generated messages using simple template strings; no external dataset is required.

**Build it:**

1. Set up a Node.js project with Express.js to simulate a bot message generator API.
2. Create a set of message templates including some with potentially offensive or stereotypical content.
3. Implement a filter module that blocks messages containing predefined offensive keywords or patterns.
4. Write tests to verify that the filter blocks unethical messages and allows acceptable ones.
5. Create a simple frontend or CLI to generate and display filtered bot messages.
6. Document how the filter relates to ethical considerations from the paper.

**Ships as:** A GitHub repo with a Node.js bot simulator, ethical content filter, tests, and README explaining the ethical motivation and implementation.

**Stretch goal:** Add a simple machine learning classifier (e.g., a keyword-based sentiment analysis) to improve filtering accuracy.

### Intermediate — Cultural Signifier Generator with Stereotype Safeguards
*Effort: 1-3 weekends, ~20 hours*

You implement a procedural character description generator that uses cultural and social signifiers (e.g., clothing, occupation, hobbies) to create diverse characters. You add safeguards to detect and block stereotypical or offensive combinations, inspired by the paper's analysis of risks in using cultural signifiers in generators.

**Why it shows you understood the paper:** This project demonstrates your grasp of the paper's core method of identifying ethical challenges in cultural signifier use and attempts a practical mitigation, reflecting the paper's key contribution about balancing meaningful signifiers without reinforcing stereotypes.

**Grounded in:** Generators that use cultural signifiers risk producing offensive or unwanted stereotypes.

**Tech stack:** Python 3.11, Flask, Jinja2, pytest

**Data:** You create a small curated dataset of cultural signifiers and known offensive stereotypes based on public domain knowledge; no external dataset is required.

**Build it:**

1. Set up a Python Flask project to serve a character generator web app.
2. Define a structured dataset of cultural signifiers (e.g., clothing styles, occupations, hobbies) with metadata about potential stereotypes.
3. Implement a generator that randomly combines signifiers to produce character descriptions.
4. Develop a rule-based filter to detect and block stereotypical or offensive signifier combinations.
5. Create a simple UI to display generated characters and indicate when a generation is blocked.
6. Write tests for generation and filtering logic and document ethical considerations from the paper.

**Ships as:** A GitHub repo with a Flask app generating culturally signified characters with stereotype safeguards, tests, and README linking to the paper's ethical discussion.

**Stretch goal:** Integrate a user feedback mechanism to flag offensive outputs and adapt filters dynamically.

*Effort: a few weeks, ~80 hours*

You design and implement an advanced procedural character generator that models a broad and inclusive space of human identities, incorporating multiple axes such as gender, ethnicity, occupation, and personality traits. The generator explicitly encodes ethical guidelines to avoid exclusion and misrepresentation, addressing the paper's limitation about balancing signifiers and modeling human possibilities.

**Why it shows you understood the paper:** This project tackles a key future direction from the paper by creating a generator that inclusively represents diverse identities while embedding ethical safeguards, demonstrating deep understanding of the paper's conceptual framework and limitations.

**Grounded in:** Designing generators that inclusively represent diverse human identities and experiences; balancing meaningful signifiers without reinforcing stereotypes is challenging and unresolved.

**Tech stack:** TypeScript, React, Node.js, Express.js, Jest, Docker
