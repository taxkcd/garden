## Paper overview

This paper introduces DECOMPOSER, a framework that converts symbolic music data (MIDI) into editable music programs written in the Strudel language. This process, called symbolic music decompilation, recovers high-level musical structure from low-level note sequences, enabling more interpretable, modifiable, and reusable music representations. The approach uses a two-stage training pipeline combining supervised fine-tuning on synthetic paired data and reinforcement learning on unpaired MIDI, optimizing for both faithfulness to the original music and code readability.

### Why it matters

**Research problem:** Recovering executable, editable music programs from symbolic music (MIDI) is challenging because MIDI flattens complex musical structure into low-level note events, and paired data of MIDI and corresponding music programs is scarce. Existing methods either produce unreadable note-by-note transcriptions or generate readable code that poorly matches the input music.

**Why it matters:** Editable music programs expose latent musical structure such as repetition and harmony, facilitating music analysis, modification, integration with creative tools, and interactive music workflows. Faithful and readable decompilation enables new applications like audio-to-code workflows, programmatic music editing, and improved music understanding.

**Key contributions:**

- Introduces symbolic music decompilation as a novel task of recovering executable music programs from symbolic music.
- Proposes DECOMPOSER, a two-stage framework combining supervised fine-tuning and reinforcement learning with execution-based rewards.
- Creates and releases STRUDEL-SYNTH, a large synthetic paired dataset of 21,174 (Strudel, MIDI) pairs generated by a frontier LLM.
- Demonstrates that an 8B parameter open-weight model trained with DECOMPOSER outperforms closed-weight frontier LLMs in MIDI reconstruction faithfulness while maintaining comparable code readability.
