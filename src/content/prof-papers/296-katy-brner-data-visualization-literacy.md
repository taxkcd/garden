# 296 · Data Visualization Literacy

## At a glance

- **Professor:** Katy Börner

- **Authors:** Katy Börner, Andreas Bueckle, Michael Ginda
- **Year:** 2019

## Paper overview

This work presents a theoretical framework for data visualization literacy (DVL), which is the ability to read, create, and explain data visualizations. It emphasizes that DVL requires literacy in text, visual literacy, and mathematical literacy. The framework supports systematic construction and interpretation of data visualizations and is designed to be theoretically grounded, practically useful, and easy to learn.

### Why it matters

**Research problem:** There is a growing need for individuals to be literate in data visualization to effectively understand and communicate data insights, but existing frameworks mostly focus on reading visualizations and lack comprehensive approaches that include constructing visualizations and consider human perception and cognition.

**Why it matters:** Being able to read and write data visualizations is becoming as important as traditional literacy in text, crucial for addressing local and global issues strategically. Improving DVL can empower broader audiences to interpret scientific data and make informed decisions.

**Key contributions:**

- Definition of DVL as encompassing text literacy, visual literacy, and mathematical literacy
- Development of a modular, extendable framework combining a typology of visualization types and a workflow process
- Integration of human perception and cognition principles into the framework
- Creation of exercises and assessments to teach and measure DVL
- Implementation of the framework in educational platforms such as Make-A-Vis and MOOCs
