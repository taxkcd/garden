## Paper overview

The InterPro database integrates multiple protein signature databases to classify protein sequences into families and identify important functional domains and sites. The 2022 update (version 90.0) includes new data, website improvements, and integration of features from the retiring Pfam website. It supports protein function prediction and structure visualization, including models from AI-based tools like AlphaFold and RoseTTAFold. InterPro also engages the public through outreach activities such as a protein families card game.

### Why it matters

**Research problem:** The rapid growth of protein sequence data due to advances in genomic technologies requires efficient and accurate methods to classify proteins and annotate their functions and structures. Existing databases and tools need integration and updating to keep pace with data growth and technological advances.

**Why it matters:** Accurate protein classification and annotation are essential for understanding biological functions, disease mechanisms, and drug discovery. Managing and interpreting the vast amount of protein data is critical for advancing molecular biology and biomedical research.

**Key contributions:**

- Integration of 1558 new member database signatures and creation of 3,280 new InterPro entries since 2020.
- Increase in UniProtKB sequence coverage from 81.3% to 82.0% despite large growth in sequence data.
- Incorporation of AI-based protein structure predictions from RoseTTAFold and AlphaFold into the InterPro website.
- Redesign of website navigation, domain architecture visualization, and addition of Pfam website features.
- Development of a protein families card game for public engagement.

### Beginner — Protein Domain Architecture Visualization
*Effort: a weekend, ~8 hours*

You build a web-based interactive visualization of protein domain architectures similar to InterPro's improved domain architecture displays. The app will parse simplified protein domain annotation data and render domain arrangements with biologically meaningful layouts and colors.

**Why it shows you understood the paper:** This project demonstrates your grasp of how InterPro visualizes protein domain architectures to aid biological interpretation, reflecting one of the key website improvements described in the paper.

**Grounded in:** Implementation of taxonomy sunburst visualization and more biologically accurate domain architecture displays.

**Tech stack:** TypeScript, React, D3.js

**Data:** Use a small synthetic dataset of protein sequences with domain annotations inspired by InterPro entries; no official dataset is provided, so you simulate domain coordinates and types.

**Build it:**

1. Create a React app scaffold with TypeScript.
2. Design a JSON schema for protein domain architecture data (protein ID, domain start/end, domain type).
3. Implement a D3.js-based horizontal layout to display domains along a protein sequence line.
4. Add color coding for domain types and tooltips with domain info on hover.
5. Add simple controls to load different protein domain architectures from local JSON files.

**Ships as:** A GitHub repo with a React app that visualizes protein domain architectures interactively, with example data and README explaining the biological context.

**Stretch goal:** Add taxonomy sunburst visualization of protein families as a complementary view.

### Intermediate — Protein Family Classification Integration Prototype
*Effort: 1-3 weekends*

You implement a simplified version of InterPro's core method: integrating multiple protein signature databases to classify protein sequences into families and annotate domains. You will combine two public protein signature datasets, run sequence searches, and merge annotations to produce integrated protein family assignments.

**Why it shows you understood the paper:** This project shows you understand the central integration challenge InterPro addresses, including combining signatures from multiple sources and annotating large protein sequence sets.

**Grounded in:** InterPro integrates 13 member protein signature databases into a single resource, updating entries regularly with new data and member database releases.

**Tech stack:** Python 3.11, Biopython, FastAPI, SQLite

**Data:** Use publicly available Pfam and SMART protein signature datasets (subsets) and a small sample of UniProtKB protein sequences as substitutes for InterPro data.

**Build it:**

1. Download and parse Pfam and SMART signature data (HMM profiles or domain annotations).
2. Select a small set of UniProtKB protein sequences for testing.
3. Implement sequence scanning against each signature database using Biopython or HMMER command-line calls.
4. Merge overlapping or complementary domain annotations from both databases per protein.
5. Build a simple FastAPI backend to serve integrated protein family annotations for queried sequences.
6. Create a minimal frontend or CLI to query and display integrated annotations.

**Ships as:** A GitHub repo with code to integrate two protein signature databases for family classification on sample sequences, with a simple API and usage instructions.

**Stretch goal:** Add basic coverage statistics comparing single-database vs integrated annotations, mimicking InterPro's coverage metrics.
